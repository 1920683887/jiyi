# Image Resources

This directory contains image resources used by the application.

## Optional Icon Files

- `app-icon.png` - Application window icon (recommended: 256x256 or 512x512 PNG)
- `piece-red-king.png` - Red King piece image
- `piece-red-advisor.png` - Red Advisor piece image
- `piece-red-elephant.png` - Red Elephant piece image
- `piece-red-horse.png` - Red Horse piece image
- `piece-red-rook.png` - Red Rook piece image
- `piece-red-cannon.png` - Red Cannon piece image
- `piece-red-pawn.png` - Red Pawn piece image
- `piece-black-king.png` - Black King piece image
- `piece-black-advisor.png` - Black Advisor piece image
- `piece-black-elephant.png` - Black Elephant piece image
- `piece-black-horse.png` - Black Horse piece image
- `piece-black-rook.png` - Black Rook piece image
- `piece-black-cannon.png` - Black Cannon piece image
- `piece-black-pawn.png` - Black Pawn piece image

## Note

Currently, the application uses Canvas-based rendering for the chess board and pieces.
These image files are optional and can be used for future enhancements or alternative rendering modes.

## Recommended Formats

- PNG with transparency for piece images
- SVG for scalable icons (requires additional JavaFX support)
- ICO format for Windows native icons
