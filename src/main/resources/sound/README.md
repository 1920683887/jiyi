# Sound Resources

This directory contains audio files used by the application.

## Required Files

- `move.wav` - Sound played when a piece moves
- `capture.wav` - Sound played when a piece is captured

## Format

- Format: WAV (Waveform Audio File Format)
- Sample Rate: 44100 Hz recommended
- Bit Depth: 16-bit recommended
- Channels: Mono or Stereo

## Note

The application will function without these files, but sound effects will be disabled.
To enable sounds, place the appropriate WAV files in this directory.

You can:
1. Record your own sounds
2. Use royalty-free sound effects from open sources
3. Extract sounds from existing chess software (ensure licensing compliance)
